# 混淆图生成器 · 像素迷藏

像素迷藏（Pixel Hideaway）是一个纯前端的图片混淆与反混淆工具。上传图片并设置口令，即可将画面打散为混淆图；使用相同口令，可以把像素还原回原来的位置。

图片和口令只在浏览器中处理，不上传服务器。

## 功能

- 支持 PNG、JPG、WebP 图片上传与拖拽。
- 使用口令生成混淆图，并导出无损 PNG。
- 支持反混淆、混淆图还原和像素完整性校验。
- 保留透明度，提供原图与结果预览。
- 支持随机口令、取消处理，以及电脑和手机布局。

## 快速开始

需要 Node.js 22 或更新版本，无需安装第三方依赖。

```sh
git clone https://github.com/AEB73D53/pixel-hideaway.git
cd pixel-hideaway
npm start
```

在浏览器中打开 [http://localhost:5173](http://localhost:5173)。

## 使用方法

1. 选择「图片混淆」，上传图片，输入口令，点击「开始混淆」。
2. 下载生成的 PNG，并保存好口令。
3. 需要还原时，选择「图片还原」，上传混淆 PNG，输入原口令。
4. 点击「开始还原」，校验通过后下载还原图片。

混淆完成后直接切换到「图片还原」，会自动载入刚生成的图片。

## 支持范围

单张图片最大 **50 MiB、1200 万像素**。还原仅支持本工具生成的 PH1 混淆 PNG，不兼容其他算法生成的混淆图。

请保留下载的原始 PNG。截图、裁剪、缩放、转成 JPG 或经其他软件重新编码后，可能无法还原。

无损还原指恢复混淆前由浏览器解码得到的 RGBA 像素；还原结果统一为 PNG，不保留原文件的 EXIF 和压缩格式。含动画的图片只处理浏览器解码的静态帧。

本工具用于视觉混淆，不提供安全加密。

## 部署

将 `dist/` 目录作为静态网站发布即可，无需构建步骤或后端服务。部署后通过 HTTPS 访问；本地运行使用 localhost，不能直接双击 HTML 使用。

## 开发与测试

```sh
npm test
```

核心测试覆盖像素置换、透明图片无损往返、PNG 编解码和损坏文件检查。

浏览器测试需要 Python、Playwright、Pillow 和 Chromium。保持本地服务运行，再执行：

```sh
python tests/browser_check.py
```
