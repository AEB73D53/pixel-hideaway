# 像素迷藏 · Pixel Hideaway

纯前端图片混淆与反混淆网站。支持拖拽上传、口令、前后预览、无损 PNG 下载和完整性检查。无需服务器处理图片、无需 API Key，也不会保存口令。

## 本地运行

安装 Node.js 22 或更新版本，然后在本目录运行：

```sh
npm start
```

打开 http://localhost:5173 。无需 `npm install`，项目没有第三方运行时依赖。图片处理需要 HTTPS 或 localhost，不能直接双击 HTML 文件运行。

## 使用

1. 在「图片混淆」上传 PNG、JPG 或 WebP，或点击示例图片。
2. 输入口令，点击「开始混淆」，下载原始 PNG。
3. 切换到「图片还原」，上传下载的混淆 PNG，输入相同口令并下载结果。混淆完成后直接切换标签，会自动载入刚生成的图片。

支持单张最大 50 MiB、1200 万像素。大型图片在内存有限的设备上可能需要缩小。含动画的格式仅处理浏览器解码的静态帧。

请保留原始 PNG；截图、压缩、重新编码、裁剪、缩放或删除参数，都可能导致无法还原。本站 PH1 算法与其他混淆工具不兼容。

## 原理与还原范围

- 口令与随机 nonce 经 SHA-256 派生种子，驱动确定性的 Fisher–Yates 像素置换。透明度与 RGB 一起搬移。
- PNG 的 `tEXt` 数据包含版本、尺寸、随机 nonce、口令验证值和原始像素 SHA-256，不包含口令明文。
- 自行编码和解码本站生成的 RGBA PNG，避免混淆后透明像素经过 Canvas 往返时丢失颜色精度。
- 还原得到上传时浏览器解码的 RGBA 像素，而不是原 JPEG/WebP 的文件字节。EXIF、原压缩参数等元数据不保留。
- Web Worker 执行混淆、PNG 编码和校验，可以取消。所有操作在本地完成，不请求外部图片服务或分析服务。

**视觉混淆不是安全加密。** 颜色分布仍可见，口令验证值可被离线尝试。请不要把本工具用于敏感文件的安全保护。口令丢失后无法找回。

## 部署

将 `dist/` 整个目录作为静态网站发布到支持 HTTPS 的托管服务即可，不需要构建步骤，也不需要配置密钥。资源全部使用相对路径，可放在子路径。

已配置 Sites 项目标识于 `.openai/hosting.json`，其中没有凭据。复制本项目另建 Sites 网站时需使用新项目的标识。GitHub 仓库与 Sites 源码托管是两个独立远程地址。

## 验证

```sh
npm test
```

覆盖置换一一对应、透明 RGBA 精确往返、窄图片、PNG 参数、错误口令和损坏文件。

可选浏览器测试需要 Python、Playwright、Pillow 和已安装的 Chromium。先启动本地服务，再运行：

```sh
python tests/browser_check.py
```

覆盖示例与实际上传、下载后重新上传还原、错误口令、透明图片、无效文件和 375/768/1024px 响应式布局。截图与下载结果写入被 Git 忽略的 `test-results/`。

## 目录

```text
dist/          可直接发布的完整静态网站
  app.js       页面交互、上传、预览、下载
  core.js      像素置换、PNG 编解码、校验
  worker.js    后台图片处理
tests/         核心和浏览器测试
server.mjs     本地静态预览服务
```

不要将任何 GitHub token、环境变量文件或凭据提交到仓库。
