# 混淆图生成器：图片混淆与反混淆工具｜像素迷藏

**像素迷藏（Pixel Hideaway）是一个可自行部署的混淆图生成器和混淆图还原工具。** 上传图片、设置口令即可生成像素打乱的混淆图；使用相同口令和原始 PNG，可以反混淆并还原图片。

项目支持图片混淆、反混淆、混淆图还原、透明图片处理和无损 PNG 下载。图片与口令均在浏览器本地处理，无需上传服务器、无需注册、无需 API Key。

项目仓库：[AEB73D53/pixel-hideaway](https://github.com/AEB73D53/pixel-hideaway)。仓库保存完整源码；使用工具请在本地启动，或将 `dist/` 部署到自己的静态网站。

## 功能

- **生成混淆图**：上传 PNG、JPG、WebP，用口令打乱像素位置。
- **反混淆与图片还原**：识别本站 PH1 混淆 PNG 中的参数，验证口令后恢复画面。
- **无损像素还原**：保留浏览器解码后的 RGBA 像素，包括透明度，完成后检查完整性。
- **本地处理**：支持拖拽上传、前后预览、随机口令、取消处理和 PNG 下载。
- **可自行部署**：纯 HTML、CSS、JavaScript，没有第三方运行时依赖，适配电脑和手机。

## 本地运行

安装 Node.js 22 或更新版本，然后在本目录运行：

```sh
npm start
```

打开 http://localhost:5173 。无需 `npm install`，项目没有第三方运行时依赖。图片处理需要 HTTPS 或 localhost，不能直接双击 HTML 文件运行。

## 如何生成混淆图和反混淆

1. 在「图片混淆」上传 PNG、JPG 或 WebP，或点击示例图片。
2. 输入口令，点击「开始混淆」，下载原始 PNG。
3. 切换到「图片还原」，上传下载的混淆 PNG，输入相同口令并下载结果。混淆完成后直接切换标签，会自动载入刚生成的图片。

支持单张最大 50 MiB、1200 万像素。大型图片在内存有限的设备上可能需要缩小。含动画的格式仅处理浏览器解码的静态帧。

请保留原始 PNG；截图、压缩、重新编码、裁剪、缩放或删除参数，都可能导致无法还原。本站 PH1 算法与其他混淆工具不兼容。

## 常见问题

### 混淆图是什么？

本项目通过打乱图片的像素位置生成混淆图，让原画面呈现为噪点。每个像素的颜色和透明度随位置一起移动；正确口令和完整的还原参数可以把像素搬回原位。

### 如何还原混淆图？

打开「图片还原」，上传本工具下载的原始混淆 PNG，输入生成时的口令，点击「开始还原」。校验通过后即可下载还原后的 PNG 图片。

### 为什么反混淆或混淆图还原失败？

请检查口令的大小写与空格，确认上传的是原始 PNG，而不是截图、聊天软件压缩后的图片或经过其他软件重新编码的文件。其他网站生成的混淆图通常使用不同算法，本项目不能通用还原。

### 可以用它安全加密图片吗？

不能。本项目提供视觉混淆，不是安全的图片加密方案。像素颜色分布仍然可见，口令也可能遭到离线尝试。请勿用于敏感资料的安全保护。

## 原理与还原范围

- 口令与随机 nonce 经 SHA-256 派生种子，驱动确定性的 Fisher–Yates 像素置换。透明度与 RGB 一起搬移。
- PNG 的 `tEXt` 数据包含版本、尺寸、随机 nonce、口令验证值和原始像素 SHA-256，不包含口令明文。
- 自行编码和解码本站生成的 RGBA PNG，避免混淆后透明像素经过 Canvas 往返时丢失颜色精度。
- 还原得到上传时浏览器解码的 RGBA 像素，而不是原 JPEG/WebP 的文件字节。EXIF、原压缩参数等元数据不保留。
- Web Worker 执行混淆、PNG 编码和校验，可以取消。所有操作在本地完成，不请求外部图片服务或分析服务。

**视觉混淆不是安全加密。** 颜色分布仍可见，口令验证值可被离线尝试。请不要把本工具用于敏感文件的安全保护。口令丢失后无法找回。

## 部署

将 `dist/` 整个目录作为静态网站发布到支持 HTTPS 的托管服务即可，不需要构建步骤，也不需要配置密钥。资源全部使用相对路径，可放在子路径。

原 Sites 演示已停止对外公开。源码中的 `.openai/hosting.json` 是历史托管配置，不包含凭据；普通静态部署不需要它，另建 Sites 项目时必须改用自己的项目标识。
